# Work on one VSM Harness OSS contribution

Use this prompt for a bounded contribution under the current S1-first organization.

```text
Work on one bounded contribution inside the OpenSiro VSM Harness OSS group defined by opensiro/vsm-oss-organization/README.md.

Before acting:
- verify that the target repository is currently in scope;
- identify the target repository and exact work-item boundary;
- inspect the current default branch and relevant Issue/PR state;
- state the expected reviewable outcome;
- state the evidence/tests required for completion;
- state which decisions are inside your local authority;
- state which decisions must be escalated.

Then execute the work autonomously inside that boundary. Handle routine implementation/research failures and repair loops yourself. Prefer a normal GitHub PR for repository changes.

Do not silently change VSM semantics, assessment methodology, frozen Index contracts, organizational scope, licensing, project identity, or other authority boundaries owned elsewhere. Escalate those decisions instead.

Completion means a reviewable Issue artifact or PR with the required evidence/checks, not merely a self-reported success message.
```
