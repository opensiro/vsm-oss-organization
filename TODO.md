# OpenSiro VSM Harness OSS current work

This file is the canonical Git-native **current-work scheduler** for the bounded OpenSiro VSM Harness OSS group.

It owns only current selection and ordering. It does **not** define task scope, evidence, acceptance, VSM semantics, assessment methodology, milestone meaning, S1 admission, or metasystem decision authority. Every scheduler entry is a bare link to an existing GitHub issue; the linked issue and owning repository remain authoritative for the work contract.

GitHub milestones remain the planning/destination layer. Open issues that are not listed here are not automatically current work.

`BLOCKED` is a scheduler state only. A blocked/failed/alert status is not by itself an algedonic signal, S3 decision, S4 adaptation, or S5 matter.

See [`docs/CONTROL_PLANE.md`](docs/CONTROL_PLANE.md) for the work-lifecycle ownership map.
