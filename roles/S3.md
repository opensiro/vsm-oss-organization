# S3 — current-control actor adapter

Use this role only after one transaction has been admitted under the canonical [`contracts/s3/current-control.md`](../contracts/s3/current-control.md) contract.

This file is an **actor adapter**, not the S3 definition and not evidence that S3 is currently established. The contract owns functional admission, decision classes, owner/support separation, return semantics, and closure requirements. Normative S3 semantics remain upstream in the selected VSM Harness Profile.

## M1 constructor mode

During M1, the decisive S3 owner may be human, parent, external actor, or another explicitly identified participant. Do not invent a permanent S3 agent.

For one admitted transaction:

1. read the canonical S3 contract and the concrete transaction record;
2. verify the system-in-focus, trigger, whole-system current view, decisive right, allowed responses, and return target;
3. identify and record the actual decision owner before attributing the decision;
4. keep schedulers, `TODO.md`, Projects, queues, CI, branch rules, validators, budgets, and other transport/enforcement machinery separate from ownership;
5. obtain or exercise only the bounded decision right assigned to the recorded owner;
6. return the decision through the first-party transaction surface;
7. require affected S1 work to acknowledge/apply or explicitly reject/escalate it;
8. preserve observable closure evidence.

If the matter is ordinary local S1 variety, do not use S3. If it is identity/ultimate-policy work, leave this path for the S5 parent boundary. A material S3* finding may trigger S3 but does not transfer S3 authority to the auditor.

## Future autonomous mode

A future `S3=A` mode is activated only when the applicable GitHub milestone/tracker establishes the required autonomous ownership and boundary-reachable closure. Until then, this role must not be read as a standing autonomous regulator.

When autonomous mode is explicitly admitted, the agent may exercise only the delegated whole-system current-control rights named by the transaction and parent-governed policy envelope. Missing authority or evidence must escalate rather than be inferred.

## Evidence output

Preserve at minimum:

```text
system-in-focus
qualifying current exception
whole-system current view
decisive current-control right
actual decision owner
returned decision
support / enforcement separately
S1 acknowledgement / application
closure evidence
final transaction state
```

Use [`../control/s3-current-control-v1.template.json`](../control/s3-current-control-v1.template.json) for the machine-readable shape and [`../templates/s3-control-record.md`](../templates/s3-control-record.md) for a reviewable record.
