# Control Plane — assessment-derived upstream replay

**Status:** Organization-owned **routing and conformance** supplement for the existing command `test S1 function: upstream contributions`. Does not replace [Control Plane](AGENT_CONTROL_PLANE.md), [assessment-to-upstream contract](https://github.com/opensiro/upstream/blob/main/docs/ASSESSMENT_TO_IMPROVEMENT.md) or [Upstream experiment #56](https://github.com/opensiro/upstream/issues/56). Maintainer review required for any new authority. Use the current public default branch before acting.

## Purpose

Reproduce a **decision method**, not a preferred candidate, a desired VSM grade or an already-known patch. A fresh Control Plane conversation must distinguish:

- `FRESH_INDEX_FIRST`: **prospective, target-blind workflow test**, with a verifiable pre-selection record and source-first candidate derivation. A matching candidate is neither expected nor required.
- `CONTINUE_PINNED_CASE`: **non-independent continuation** of a user-named existing issue/PR. Reuses its preserved baseline/receipts, reads today's actual owner status and performs the next admissible action. Never presents rediscovery as blind.

A replay is not yet evidence of **autonomous S1**, actual production benefit or external merge. Strictly separate `origin_class` from `execution_stage` and `effect_verdict`.

## FRESH_INDEX_FIRST — fresh-chat executable route

**Entry command in a new conversation:** `test S1 function: upstream contributions`. Say explicitly: *independent, Index-first assessment-derived discovery; do not use earlier chats, saved candidate lists, previous case conclusions, Upstream PR titles or user memory for candidate selection*. Follow [START_HERE](../START_HERE.md) → [ECOSYSTEM](ECOSYSTEM.md) → [AGENT_CONTROL_PLANE](AGENT_CONTROL_PLANE.md); identify `opensiro/upstream` as the **adjacent** engineering owner, not an admitted Organization S1 domain.

**Selection firewall:** bootstrap / method / rights may be inspected first, but do **not** read issue #56's case narrative, any dated case receipt under `docs/reviews/`, `pilots/`, `candidates/`, pre-existing pilot PRs or upstream issue/PR search results as discovery inputs **before a candidate is selected and its origin committed to a visible record**. The ordinary Control Plane contract may name the experiment/owner without revealing the case. If the session is already exposed to candidate names through memory or prior prompts, label the run `POTENTIALLY_CONTAMINATED` and do **not** claim an independent first attempt. No agent can guarantee a genuinely blind context merely by instruction.

### Required first-pass checkpoints

1. **Current Index:** retrieve the current canonical `opensiro/vsm-harness-index` default branch commit. Independently inspect included harness assessments and select one based on a **specific function, actual decision owner, observable missing feedback/closure and source evidence**; not an empty autonomy state or desired target. Follow the currently published Skills Methodology for interpreting S1/S2/S3/S3*/S4/S5.
2. **Selection lock before target investigation:** record `selected_index_sha`, `assessment_path`, `review_ref`, `selected_function`, `finding_quote_or_source_anchor`, `hypothesized_native_behavior`, `counterexample_or_null`, and `selection_time/source_order` in a fresh operator-visible research note or reviewable **OpenSiro-owned** artifact, **before** consulting target GitHub issues, existing Upstream pilot logs or candidate cards. If not reliably established, set `origin_class=INSUFFICIENT`, not `ASSESSMENT_DERIVED`. Do not alter the Index assessment.
3. **Current native owner/fit:** only now inspect the selected harness's true current default branch, first-party product plan and source, contributor policy/CLA, duplicate issues/PRs and live product constraints. Record four independent gates: `need`, `mechanism`, `counterfactual_value`, `scope`, each `PASS/PENDING/FAIL`. Confirm that the *assessment finding*, not a later convenient issue, motivated selection. A pre-existing upstream issue can corroborate need without retroactively causing the Index finding.
4. **Freeze measurable before/after before writing:** define the **unaltered product baseline** and target environment, real user-visible failure or coordination shortfall, matched changed-source workload and controls, effect metric/threshold, preservation of independent tasks, invalid/unknown scope and safety handling, regression/rollback plan and credible null/negative result. Native product acceptance precedes performance of CI on a contrived helper. If only hypothetical manager decisions or synthetic task descriptions are available, return `BENEFIT_NOT_MEASURED`.
5. **Execute only within live authority:** apply the existing [Upstream S1 test](https://github.com/opensiro/upstream/blob/main/docs/ASSESSMENT_DRIVEN_S1_TEST.md), [Upstream #6](https://github.com/opensiro/upstream/issues/6) actor/stage/permission checks, and [Organization #274](https://github.com/opensiro/vsm-oss-organization/issues/274) non-admission boundary. Read-only investigation and OpenSiro-owned reviewable internal prototype work may be separately admissible, **but the read-only test command itself authorizes no write**. An external GitHub fork/branch, issue, contact, PR publication or merge must independently satisfy effective rights and first-party rules; a generic `продолжай`, token presence or absence of maintainer refusal is **not** authorization.
6. **Verify and return:** inspect exact source PR head, native tests and matched product pre/post separately, record fail/negative outcomes and actual human decisions; check live upstream merge/acceptance rather than inferring it. Read [#56](https://github.com/opensiro/upstream/issues/56) and earlier case receipts **after locking the fresh candidate** to compare selection and outcome with prior practice. Do **not** rewrite an earlier receipt or silently change the chosen target because a previous case looks easier.

### Final evaluation for a new-session Control Plane

Report a concise, source-linked matrix with `origin_class` (`ASSESSMENT_DERIVED` / `ASSESSMENT_INFORMED` / `GENERAL_UPSTREAM` / `INSUFFICIENT`), `selection_lock`, `native_fit`, `baseline`, `intervention`, `after`, `effect_verdict`, `external_publication`, `maintainer_disposition`, `authority_used`, `human_interventions`. Mark each as `OBSERVED / PENDING / BLOCKED / NOT_TESTED` with actual refs, not assumed completion.

**Passing the routing test** means demonstrably following these decision/provenance/authority stages and honestly stopping at an unsupported gate. **Passing the full practical cycle** additionally requires native source-level causal benefit, matched actual product behavior, permitted upstream submission and actual maintainer feedback. The full cycle has not been established by a planning-only prototype or internal green CI. A different well-founded candidate, a correct `NO_ELIGIBLE_ASSESSMENT_CANDIDATE`, or `BLOCKED_EVIDENCE` is a **valid** result. Do not try to reproduce an exact target name.

## CONTINUE_PINNED_CASE — non-blind operational continuation

Use only when the operator explicitly supplies an existing issue/PR or says to resume that named case. Read current [Upstream #56](https://github.com/opensiro/upstream/issues/56), the exact [case-owning issue](https://github.com/opensiro/upstream/issues/61), its implementation PR and [dated case receipt](reviews/2026-10-22-agentbox-control-plane-case-receipt.md). Re-fetch actual Index / target `main` / source SHA / live CI / PR threads before action; frozen case refs are historical evidence, never current assumptions. Reuse executed baselines rather than running them again to inflate progress. Work until the next **real technical or authority stop**, including a measured `NO_BENEFIT` or first-party design mismatch, then return the boundary. No false independent selection claim.

## Organizational and consent boundaries

This handoff **does not** add work to `TODO.md`, change scope, admit `opensiro/upstream` as a fourth S1 domain, select an S5 decision, assign an S3/S3* owner, authorize external GitHub writes, start background agents, trigger a blind external reviewer, or change an Index grade. The bounded operational S1 domains remain Index, Skills, Awesome. Organization #274 is `PROPOSED / NOT ADMITTED` unless a **future live owning source** proves a separately made/applied S5 decision. Source-local Upstream engineering, experiment #56 and its pilot issues remain **Upstream-owned**; the Control Plane here merely routes them.

## Acceptance for this document

- Fresh replay can start **without disclosing the previous winner** and lock a candidate before using historical Upstream issue/PR narratives.
- Named continuation can recover current exact PR/CI/candidate/known negative results without pretending independence.
- Both routes bind provenance, native function, four gates, unaltered baseline and matched effect, not an autonomy-grade objective.
- No easy issue hunting substitutes for an unsupported Index finding; no synthetic helper CI is reported as prevented production failures.
- No claims of external write rights, maintainer acceptance or a fourth S1 domain without a current attributable source.
- Outcome may be success, falsification, null or precise `BLOCKED`; never an automatic `S1=A` grade.
