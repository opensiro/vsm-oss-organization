# VSM OSS Organization

A minimal organizational profile for autonomous OpenSiro OSS contributors.

This repository applies, but does not redefine, the public [VSM Harness Profile](https://github.com/opensiro/vsm-harness-profile). It is being built bottom-up using an OSM-style elimination method: add an organizational function only when a concrete variety/disturbance cannot be absorbed by the functions already present.

Current normative dependency: VSM Harness Profile `0.2.0`.
Current assessment notation/methodology dependency: VSM Harness Methodology `0.2.2`.

The repository is intentionally minimal while the first autonomous S1 contribution contract is being defined.
