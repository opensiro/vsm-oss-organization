# Organizational records

`records/` contains reviewable evidence produced by concrete organizational executions or bounded evidence snapshots.

Records are downstream of contracts:

```text
contract
  ↓ executed by an identified owner / composed actor
record
  ↓ reviewed as evidence
assessment interpretation
```

A template is not a record, and a record is not automatically a positive autonomy grade. The selected Profile/Methodology still governs function mapping and ownership classification.

Current record families:

- `s1/` — operational S1 construction/coverage evidence;
- `s5/` — concrete S5 parent-decision witnesses;
- `assessment-snapshots/` — explicitly non-canonical bounded assessment/pre-assessment snapshots used to audit this reference implementation against the general Methodology.
