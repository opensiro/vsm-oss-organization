# Experiments

This directory contains **non-normative research surfaces** owned by `opensiro/vsm-oss-organization` while they are being tested.

Experiments here do not change:

- the canonical bounded-organization metric contract in `METRICS.md` / `metrics.yaml`;
- VSM semantics;
- assessment methodology;
- canonical Index assessments;
- organizational authority or system boundary.

Each experiment must be self-contained, state its evidence and anti-gaming rules, and make promotion/extraction explicit. A successful experiment may later move into its own repository or be promoted through a separate governed change.

Current experiments:

- [`upstream-intervention-fit/`](upstream-intervention-fit/) — tests whether OpenSiro-motivated upstream interventions have standalone product-native value for the upstream project.
