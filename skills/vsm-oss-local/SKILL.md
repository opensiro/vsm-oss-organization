These are agent workflow prompts, not CLI subcommands. For assess/upgrade/validate/reassess/status, reuse the generic skill and Organization-local rights, not a second implementation. Only a separate explicit implementation instruction can authorize changes. The ordinary `upstream roadmap` command remains for the external contribution domain; do not special-case it here or in Upstream.

The local subject is the actual bounded public VSM OSS recursion, not every repository in the organization. Reuse an attributable source-pinned local assessment. A preliminary local mapping (with exact date, source, versions, scope, limitations and preserved text) can support a **provisional construction hypothesis** after checking current evidence; it does not establish an independently reviewed full assessment or authoritative new grade. If the selected function or necessary authority/source is unresolved, report BLOCKED. No Index admission required by this local route, no claim of an accepted Index assessment, no fork, no opensiro-contributions metadata or production statistics.

No public external outreach, no fork, no automatic upgrade, reassessment or S5 act. A merged research plan is not milestone completion.
